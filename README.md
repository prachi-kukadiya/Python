## ▶️ How to Run the Programs

### 1. Install Python

Download and install Python from the official Python website.

### 2. Clone the Repository

```bash
git clone https://github.com/prachi-kukadiya/Python.git
```

### 3. Open the Project

Open the downloaded folder in **Visual Studio Code**.

### 4. Run a Python File

Use:

```bash
python filename.py
```

For example:

```bash
python program.py
```
